Uzumaki for Linux, any distro

Download one AppImage file, or build from source. No sudo. Wayland and X11.

macOSArch LinuxAppImage · any distroWindows

What you need

  • A 64-bit Intel or AMD PC (x86_64) running Linux.
  • A GPU with Vulkan: the Vulkan loader and your GPU’s driver.
  • An Apple Music subscription, to stream. Your own music files play without one.

Wayland and X11 both work. On X11 you also need libxkbcommon-x11 from your distro (libxkbcommon-x11-0 on Debian and Ubuntu): Uzumaki loads it at start-up and stops without it. On Arch, use the AUR package instead.

Option 1: the AppImage

One file, no install, no sudo. It works on most distros.

  1. Download Uzumaki-0.1.0-x86_64.AppImage from the release page. Keep it anywhere you like, for example in ~/Applications.
  2. Make it executable.
  3. Run it.
$ chmod +x Uzumaki-0.1.0-x86_64.AppImage $ ./Uzumaki-0.1.0-x86_64.AppImage

Coming in 0.1.1.

On the first start, sign in to Apple Music from the banner. The Widevine module that plays the music downloads by itself then.

If it won’t start, your distro may be missing FUSE 2, which AppImages need. Install libfuse2 (Debian, Ubuntu) or fuse2 (Arch) and try again. Without FUSE you can still run it with ./Uzumaki-0.1.0-x86_64.AppImage --appimage-extract-and-run.

Option 2: build from source

For when you want to build it yourself. You need:

  • Rust with cargo, Node.js with npm, git and pkg-config.
  • The ALSA development files (alsa-lib, libasound2-dev or alsa-lib-devel, depending on your distro).

The install script checks for the tools and tells you what is missing. It builds a release binary and installs for your user, with no sudo.

$ git clone https://github.com/hanami117/uzumaki.git $ cd uzumaki $ ./install.sh

You can also unpack the source tarball from the release page and run ./install.sh in it.

It installs into ~/.local (set PREFIX=... for another place):

  • ~/.local/bin/uzumaki and ~/.local/bin/uzu;
  • ~/.local/share/uzumaki/bridge/, the playback bridge with castLabs Electron (about 290 MB);
  • the app-menu entry and icons.

The first build takes a few minutes. If ~/.local/bin isn’t on your PATH, start Uzumaki from your app menu. Sign in to Apple Music from the banner on the first start.

Updates

Uzumaki shows a notice when a new version is out. It never downloads or installs anything by itself. Quit Uzumaki first.

  • AppImage: the notice has a Download button. Download the new AppImage, then replace the old file with it.
  • From source: pull the new code and run the install script again.
$ git pull && ./install.sh

Uninstall

Quit Uzumaki first.

  • AppImage: delete the file. If you added it to your app menu with a helper tool, remove it there too.
  • From source: run this in the source folder.
$ ./install.sh --uninstall

Your login, settings and caches stay in ~/.config/uzumaki and ~/.cache/uzumaki. Delete those two folders to forget everything.
