Uzumaki for Windows

Planned, but not yet.

macOSArch LinuxAppImage · any distroWindows

Coming soon There is no Windows version yet.

Why not yet

Uzumaki plays Apple Music through Apple’s own web player, and that player needs Widevine. Getting Widevine to work on Windows takes extra work, including signing for Widevine (VMP). That work is still ahead, so there is no date.

What to do now

Linux and macOS come first. Follow the GitHub page for news, or @Uzumaki_App on X.

For now, see the macOS, Arch Linux and AppImage pages.
