Uzumaki for Windows

Windows 10 or 11, x64. Run the installer, or unzip it anywhere. No administrator rights.

macOSArch LinuxAppImage · any distroWindows

Download the installer Download the zip

What you need

  • A 64-bit Intel or AMD PC (x64) with Windows 10 or Windows 11.
  • An Apple Music subscription, to stream. Your own music files play without one.

Install with the installer

  1. Download the installer (the button above, or Uzumaki-0.4.2-windows-x64-setup.exe from the release page).
  2. Run it. If Windows shows a blue “Windows protected your PC” window, see First launch below.
  3. Follow the steps. Setup installs Uzumaki for you only, into %LOCALAPPDATA%\Programs\Uzumaki, and never asks for administrator rights. It adds a Start menu entry (a desktop shortcut is optional) and puts the uzu command on your PATH.
  4. Start Uzumaki from the Start menu and sign in to Apple Music from the banner. The Widevine module that plays the music downloads by itself on that first start.

First launch

Uzumaki isn’t code-signed yet, so Windows SmartScreen shows “Windows protected your PC” the first time you run the installer or the app. This is expected for a new open-source app. Click More info, then Run anyway. If you want to check the file first, the .sha256 checksums are on the release page.

Install from the zip

The zip is the same app without an installer. Nothing is added to the Start menu or your PATH.

  1. Download the zip (the button above, or Uzumaki-0.4.2-windows-x64.zip from the release page).
  2. Unzip it anywhere you like, for example C:\Uzumaki, and keep the folder whole.
  3. Run uzumaki.exe. To use uzu from the folder, run .\uzu in PowerShell.

What works on Windows

  • Apple Music: sign in with your Apple ID. Playback runs through castLabs’ Electron with Widevine, the same as on the other systems.
  • Your own music files in the same queue.
  • Media keys and the Windows media overlay (SMTC), song notifications, a tray icon and start at login.
  • Discord status, and the uzu command line, which talks to the app over a named pipe.

What is not on Windows

  • AirPlay is not available.
  • Animated artwork needs ffmpeg.exe on your PATH.

Updates

Once a day Uzumaki asks this site whether a new version is out, and shows a notice if there is. Settings → Advanced turns the check off. It never downloads or installs anything by itself. To update, download the new installer and run it over the old one. Your settings and sign-in stay.

Uninstall

Quit Uzumaki first.

  • Installer: open Settings → Apps → Installed apps, find Uzumaki and click Uninstall. It asks whether to remove your data too.
  • Zip: delete the folder.

Your settings are in %APPDATA%\Uzumaki. Caches and logs are in %LOCALAPPDATA%\Uzumaki, and the logs in %LOCALAPPDATA%\Uzumaki\Logs. Delete those folders to forget everything.
