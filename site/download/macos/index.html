Uzumaki for macOS

Apple silicon, macOS 13 or later. Install from a disk image or with Homebrew.

macOSArch LinuxAppImage · any distroWindows

Beta Version 0.2.0 is out. Release notes and checksums are on the release page.

Download the DMG

What you need

  • A Mac with Apple silicon (M1 or later).
  • macOS 13 Ventura or later.
  • An Apple Music subscription, to stream. Your own music files play without one.

Install from the disk image

  1. Download the DMG (the button above, or Uzumaki-0.2.0.dmg from the release page).
  2. Open it, and drag Uzumaki to your Applications folder.
  3. Eject the disk image.

First launch

Uzumaki isn’t notarized by Apple yet, so macOS stops it the first time. This is expected. You only do this once.

  1. Open Uzumaki from Applications. macOS says it can’t check the app. Close that message.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Click Open Anyway next to Uzumaki, then confirm with your password or Touch ID.

Or, in Terminal, remove the quarantine mark yourself:

$ xattr -dr com.apple.quarantine /Applications/Uzumaki.app

Then sign in to Apple Music from the banner in the app. The Widevine module that plays the music downloads by itself on that first start.

Install with Homebrew

The cask comes from Uzumaki’s own tap. It puts Uzumaki in Applications and adds the uzu command. The first-launch steps above still apply.

$ brew install --cask hanami117/uzumaki/uzumaki

Homebrew 7 only installs third-party casks you trust. The full name above trusts the cask for you. If you ran brew tap hanami117/uzumaki first and install by the short name, run brew trust --cask hanami117/uzumaki/uzumaki once.

Updates

Once a day Uzumaki asks this site whether a new version is out, and shows a notice if there is. It never downloads or installs anything by itself. Settings → General turns the check off.

  • Disk image: download the new DMG, quit Uzumaki, and drag the new app over the old one in Applications.
  • Homebrew: the notice tells you to update with Homebrew.
$ brew update && brew upgrade --cask uzumaki

Uninstall

Quit Uzumaki first.

  • Disk image: drag Uzumaki from Applications to the Trash.
  • Homebrew: brew uninstall --cask uzumaki. Add --zap to remove your settings and caches too.

Your login and settings stay on the Mac after a plain uninstall. To forget everything, delete these folders: ~/.config/uzumaki, ~/.cache/uzumaki, ~/.local/state/uzumaki, ~/.local/share/uzumaki, ~/Library/Application Support/uzumaki and ~/Library/Logs/Uzumaki. The sign-in also leaves a “Safe Storage” item in Keychain Access, which you can delete there.
